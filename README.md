# stock-simulator · A股模拟炒股

本地运行的 A股模拟炒股引擎，Python 实现，完整可运行。初始本金 **1 亿元人民币**，交易规则严格对标 A股实盘，所有数据本地存储、不接入真实资金、不上传任何服务器。

## 资源说明

- **行情数据源**：统一调用 `westock-data` 技能（`westock` CLI）获取 A股实时行情 / K线 / 基本面。
- **离线演示**：内置 `MockProvider`，无需联网即可运行演示与单元测试。当 `westock` 未安装时自动回退。

## 交易智能体（稳定复利策略）

量化交易专家主导、Python 开发配合实现，统一调用 `westock-data` 技能获取行情与基本面。
基础配置（本金/手续费/T+1/整手/时段）保持不变；在此基础上叠加选股池、多因子、仓位、买卖与风控铁律。

### 1. 选股池（仅沪深主板）

- 彻底剔除科创板（`688`）、创业板（`300`/`301`）、北交所（`bj`）。
- 基础剔除：ST/*ST、近一年净利润亏损、股权质押率 >50%、近 30 日日均成交额 <500 万元。
- 优先从沪深 300（`sh000300`）、中证 500（`sz399905`）的主板成分股中选股（成分内再剔除科创/创业）。

### 2. 多因子选股（按权重排序）

| 因子 | 权重 | 口径 |
|---|---|---|
| 质量 | 35% | 连续 3 年 ROE>10% + 经营现金流覆盖净利润 + 毛利率稳定 |
| 估值 | 25% | PE/PB 近 3 年分位 ≤30% |
| 低波动 | 25% | 近 6 月日收益率波动率低于全市场前 40%，阶段最大回撤 <15% |
| 动量 | 15% | 近 1 月小幅跑赢指数（超额>0），不追高（月涨幅 ≤15%） |

### 3. 仓位管理

- 总仓位 20%–80%，永久保留 ≥20% 备用现金。
- 单股 ≤ 总资金 5%，单行业 ≤ 总资金 15%。
- 分批建仓：首仓 40%，盈利前提下回调 2% 加 30%，再回调 2% 加剩余 30%。
- 亏损头寸绝不补仓；仅盈利头寸可加仓。

### 4. 买卖交易规则

- 持股周期 5–15 个交易日（中线波段）。
- 止盈：单只盈利 8% 止盈 50% 仓位；盈利 15% 全部清仓。
- 止损：单只浮亏 3% 无条件全额止损。
- 单周新开仓 ≤5 只，单周总交易次数 ≤5 次。

### 5. 风控铁律（不可突破）

| 触发 | 动作 |
|---|---|
| 单日账户总回撤 ≥1.5% | 当日强制降总仓位至 <30%；次日暂停开新仓 |
| 单周账户总回撤 ≥3% | 进入防守模式，只卖不买，总仓位 ≤20% |
| 账户从历史高点回撤 ≥5% | 全面防守，仅保留 ≤10% 底仓（只卖不买） |

> 所有阈值 / 权重集中在 `config/strategy.py`，便于回测调参与审查。

## 自学习进化（夏普优先）

交易智能体在收盘后（默认 15:30）自动复盘当日所有交易并持续进化。**优化目标统一为夏普比率最大化，约束优先级：① 控制回撤 ② 提升胜率 ③ 提升收益**。所有进化参数自动落盘 `data/learned_params.json`，下次交易自动加载。

### 1. 每日收盘复盘与盈亏归因

`agent.review(day)` 读取当日退出流水（每笔卖出均记录 `reason` 与 `entry_factors`），对每笔交易拆解盈亏原因：

- **选股错误**：因子（尤其质量）评分偏高却亏损 → 选股信号失效。
- **买点不佳**：非系统性下跌中浮亏，或持有到期仍亏损 → 入场时点偏差。
- **系统性风险**：大盘同向下跌驱动的亏损 → 市场 Beta 主导。
- **止盈止损触发** / **持有到期**：由交易规则（止盈/止损/时限）驱动了结。

归因结果写入学习进度，并累计到各因子「有效性」。

### 2. 参数迭代

- **因子权重动态迭代**：依据盈亏归因累计 `因子有效性 = Σ(单笔收益率 × 因子子分)`，用学习率 `tanh` 缩放后提升盈利因子权重、压低失效因子影响；自适应模式下（默认）不设上下限，仅保证非负并归一化（配置 `learn_lr` / `learn_eff_scale` / `adaptive_factors`）。关闭 `adaptive_factors` 时回退为夹在 `[factor_weight_min, factor_weight_max]`。
- **每 5 个交易日历史回测**（`learn_backtest_every`）：对选股池标的用历史收盘价网格搜索止损/止盈/单股仓位组合，按「夏普 → 回撤 → 胜率 → 收益」字典序择优，自动更新 `stop_loss_pct` / `tp1_pct` / `tp2_pct` / `single_stock_max`。
- **市场行情连续读数 → 配置比例自适应**：依据优先指数连续读取趋势（相对均线偏离）、年化波动率、近期回撤，由学习系统连续调制总仓中枢（`base_total_target`）、单股/单行业上限与因子偏好倾斜（牛市偏动量、高波动/回撤偏质量与低波）。开启 `adaptive_position` / `adaptive_factors` 后**不设固定上下限**，仅裁剪到物理可行域（总仓∈[0,1]、不可杠杆；权重非负）。风控铁律（回撤状态机）仍作为不可突破的应急刹车保留。

### 3. 风格校验与纠偏（每周）

`agent.style_check()` 每周检测漂移并自动卖出纠偏：

- 总仓位 > 风控应急上限（仅 NORMAL 模式无硬性上限，由学习系统目标仓位驱动；进入防守模式时按回撤铁律降至 30%/20%/10%）→ 降至上限。
- 单股 > 当前单股上限（学习系统按波动连续设定）→ 降至上限。
- **追高题材**：高估值分位（PE 近 3 年 >85%）且高动量入场 → 减仓至半仓。

### 4. 持久化与学习进度曲线

- 优化后的因子权重 / 止损止盈 / 仓位参数写入 `data/learned_params.json`，智能体启动即加载（实现「下次交易自动加载最新参数」）。
- 每次迭代追加一条进度记录到 `data/learning_progress.jsonl`：迭代序号、日期、市场风格、收益率、夏普比率、最大回撤、胜率、因子权重。
- `learner.export_progress_chart()` 生成 `data/learning_progress.html`（内联 SVG，无外部依赖），含累计收益率 / 夏普 / 最大回撤 / 因子权重演化四张曲线。

## 设计要点（量化视角）

- **手续费**：三费分离计费，佣金双向且设最低 5 元；印花税仅卖出单边计入。
- **T+1**：持仓 `available` 与 `quantity` 分离，跨交易日释放；挂单冻结股票仍保持冻结，避免重复卖出。
- **涨跌幅**：优先使用 `westock` 返回的涨停/跌停价执行限制；无行情时按股票名称是否含 'st' 判定涨跌停幅度（ST 股 ±5%，其余主板 ±10%）。
- **交易时段（撮合窗口）**：撮合引擎仅在连续竞价时段（9:30–11:30、13:00–15:00）执行；9:00–9:30 为盘前 / 集合竞价准备时段，本系统不实现集合竞价的独立撮合算法（已在 `core/trading_rules.py` 显式声明），该时段不撮合。
- **撮合**：市价单按当前价成交（含 5bps 滑点）；限价单触价成交，未触达挂单（冻结资金/股票），可重试或撤单。
- **行情展示一致性**：看板只读 `data/live_prices.json`（与撮合引擎同源），交易时段每 3s 刷新、与看板重绘对齐；空快照 / 异常价显式提示「行情数据未就绪」，绝不回退虚构演示价；展示价旁携带 `updated_at` 时效戳与 `source` 数据源状态；停牌 / 涨跌停状态显式标识。
- **盈亏**：持仓成本采用成交价加权（不含费），已实现/浮动盈亏与税费口径分离，便于回测核对。
- **本地化**：所有状态落盘 `data/`，纯本地、可复现，无任何外部上报。
